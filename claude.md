# Project rules

- For any code change (write, refactor, review), use the `high-mid-maintainable-code` skill.
- Talk to me in English. Code, identifiers, comments and commit messages in English.
- Stack: Bun, Next.js, Elysia, Drizzle, Postgres. Monorepo with Bun workspaces.
- Before pushing code, read `docs/architecture/03-git-workflow.md` and follow it for the push: branch name, commit message, pull request and merge rules.
